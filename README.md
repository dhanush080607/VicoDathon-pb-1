## 🏆 VicoDathon Hackathon

**ABTalks — 60-Day Coding Challenge** is a hackathon redesign focused on one core problem:

> **How do we make students want to keep building every single day?**

Instead of creating another course dashboard, this product turns coding into a **visible 60-day journey** built around:

```text
BUILD → COMMIT → SHARE → REFLECT → IMPROVE
```

# 🎯 The Problem

College students often know *how* to learn programming but struggle with **consistency and visibility**.

Typical problems:

```text
Learning
   ↓
Watching tutorials
   ↓
Building occasionally
   ↓
Losing momentum
   ↓
No public proof
   ↓
Weak portfolio
```

ABTalks changes the journey:

```text
Challenge
   ↓
Daily Build
   ↓
GitHub Commit
   ↓
LinkedIn Proof
   ↓
Reflection
   ↓
Streak
   ↓
Portfolio
```

---

# 💡 Product Vision

ABTalks is designed around a simple principle:

> ### Don't just learn code. Build proof.

Every completed day contributes to a student's developer journey.

By Day 60, the student doesn't just have a certificate or course completion.

They have:

* Projects
* GitHub activity
* LinkedIn activity
* Reflections
* Achievements
* A visible learning streak
* A stronger portfolio

---

# 📱 Designed for 390px First

The product is intentionally designed around a **390px mobile viewport**.

Why?

Because the real user is a college student using their phone after classes, assignments, and college work.

### Mobile UX priorities

| Principle     | Implementation               |
| ------------- | ---------------------------- |
| 👆 Touch      | Large interactive targets    |
| 👀 Scan       | Strong visual hierarchy      |
| 🌙 Night use  | Dark-first interface         |
| ⚡ Speed       | Focused daily actions        |
| 🔥 Motivation | Streaks & achievements       |
| 📈 Progress   | Visual journey               |
| 🧠 Clarity    | One primary action per state |

# 📝 Reflection Journal

After completing a challenge, students don't simply press "Done."

They reflect.

> **What challenge did you overcome?**

This creates a personal history of learning instead of just a number on a dashboard.

# ⚙️ Run Locally

### 1. Clone

```bash
git clone https://github.com/dhanush080607/VicoDathon-pb-1.git
```

### 2. Enter project

```bash
cd VicoDathon-pb-1
```

### 3. Install

```bash
npm install
```

or:

```bash
bun install
```

### 4. Start

```bash
npm run dev
```

or:

```bash
bun run dev
```

### 5. Open

```text
http://localhost:5173
```
