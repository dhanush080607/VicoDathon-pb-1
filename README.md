# 🧠 What Is ABTalks?

**ABTalks** is a 60-day coding challenge experience designed to help college students build consistency, create public proof of work, and develop a stronger developer portfolio.

Instead of simply asking students to learn every day, ABTalks encourages them to:

```text
              ┌─────────────────┐
              │   CHOOSE TRACK   │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │   BUILD DAILY   │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │  GITHUB COMMIT  │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │ LINKEDIN PROOF  │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │    REFLECT      │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │   KEEP STREAK   │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │    DAY 60 🚀    │
              └─────────────────┘
```

---

# 🎯 The Problem

College students often face a gap between **learning** and **showing what they can actually build**.

### Traditional journey

```text
Tutorial
   ↓
Practice
   ↓
Another Tutorial
   ↓
Random Project
   ↓
Lose Motivation
```

### ABTalks journey

```text
Challenge
   ↓
Build
   ↓
Commit
   ↓
Share
   ↓
Reflect
   ↓
Track
   ↓
Grow
```

The product turns daily coding into a **visible, measurable journey**.

# 💡 Product Philosophy

> ### Don't just learn code. Build proof.

A student shouldn't finish 60 days with only a completion number.

They should finish with:

```text
60 Days
   +
Daily Builds
   +
GitHub Activity
   +
LinkedIn Proof
   +
Learning Reflections
   +
Achievements
   =
A Stronger Developer Portfolio
```

## 📊 02 — Student Dashboard

### `/dashboard`

The dashboard is the student's daily command center.

> **Where am I?**

> **How close am I to Day 60?**

      ↓

# 🔥 Streak Engine

Consistency becomes visible.

Example:

```text
🔥 11 DAY STREAK

01 ✓   02 ✓   03 ✓   04 ✓   05 ✓
06 ✓   07 ✓   08 ✓   09 ✓   10 ✓
11 ✓   12 →   13 🔒   14 🔒   15 🔒
```

The current day receives a visual focus state while future days remain locked.

---

# ⚡ Momentum Score

The dashboard introduces a **Momentum Score** to make progress easier to understand.

```text
        ╭───────────╮
        │    87     │
        │   /100    │
        ╰───────────╯

  You're ahead of 74%
     of participants
```

The prototype represents momentum using signals such as:

* Consistency
* Challenge progress
* GitHub activity
* LinkedIn sharing

The core ABTalks principle:

```text

        +
Commit URL
```

```text

```

The prototype includes input validation and submission states.

# 📝 Reflection Journal

After building, students reflect on the experience.

### Questions

> What did you learn today?

> What challenge did you overcome?

The prototype stores the reflection through client-side state/local persistence.
